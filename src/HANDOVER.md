## 1. このプロジェクトは何か

マレーシアのショッピングモール「ららぽーとBBCC（LaLaport Bukit Bintang City Centre、全292店）」を、スマホで使うためのHTML攻略ブックです。日本語で検索して、日本語のジャンルで絞り込み、地図で区画番号を照合できます。GitHub Pagesで公開しています。

仕組み：`index.html`（小さなローダー）が、毎回キャッシュを回避して本体 `app.html` を読み込んで表示します。そのため、`app.html` を更新するだけで、同じURLのまま中身が最新になります。

GitHubリポジトリ：https://github.com/HIRASAWA22/lalaport-bbcc （ブランチ `main`）

## 4. ソース構成（zipの中身）と作り方

作業環境はスレッドごとに毎回まっさらになるため、ソースはこのzipが唯一の正本です。zipを展開して使います。

- `gen.py` … メインの生成器。店データ＋各種辞書を統合して `shops.json` を出力
- `hooks.py` … 各店の一行「売り」文（キャプション由来。無いものは空欄）
- `cuisine_tags.py` … 料理ジャンルのタグ辞書
- `specific_tags.py` … 各店の固有キーワード（熟成肉／A5／ボンボローニ等）
- `imgs.py` … ロゴ画像URL
- `jp_index_raw.txt` … 英語→日本語の検索インデックス素データ
- `raw_shops.txt` … 元の店舗リスト（店名・フロア・区画）
- `shops.json` … gen.py が出力する292店の中間データ（再生成されるので手で編集しない）
- `build_html.py` … `shops.json` から本体HTMLを組み立てる（CSS/JS全部入りの1ファイル）
- `verify.py` … 検証用
- `loader_index.html` … ローダーの控え

ビルド手順（このコマンド一発で `app.html` まで作れます）：

```
python3 gen.py >/dev/null 2>&1 && \
python3 build_html.py && \
cp lalaport_bbcc_book.html /mnt/user-data/outputs/app.html
```

## 6. 画面の構成（現状）

- タブは3つ：**検索／マップ／早朝深夜**
- 検索ボックスのプレースホルダーは「日本語でOK」だけ
- 「推し（推しレコメンド）」タブは**廃止済み**（関連コード・データも全削除）
- 検索カードは2列・ロゴ主役。カードに「🗺 地図」ボタンがあり、押すと地図画面で選択店の名前＋大きな区画番号を表示（ロゴは出さない方針）
- 地図は上部の館名バナーを高さ比9%でカット、ズーム（縮小／フィット／拡大）＋パン操作あり
- フィルターボタンはトグル式（押してON／もう一度でOFF）、複数選択可（同種はOR・別種はAND）、結果は検索インデックスと一致
